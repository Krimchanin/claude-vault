# Security policy

Claude Vault handles highly private local conversation data. Do not disclose vulnerabilities involving data exposure, unsafe path handling, or destructive restore behavior in a public issue.

Until a private reporting address is published, create a minimal public issue containing no exploit details or personal data and ask the maintainers for a private contact channel.

Only the latest release receives security fixes. Never attach a real vault, transcript, or Claude application-data directory to a report.
