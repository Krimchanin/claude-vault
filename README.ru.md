# Claude Vault

[English](README.md) · **Русский** · [简体中文](README.zh-CN.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md)

**Переключайте аккаунты Claude, не теряя историю диалогов.** Claude Vault — неофициальное локальное приложение для просмотра, резервного копирования и восстановления данных Claude Desktop и Claude Code напрямую из файловой системы.

Claude Desktop может очищать видимые локальные чаты при смене аккаунта. Claude Vault переносит метаданные сессий, полные JSONL-транскрипты, вложения и рабочие файлы в независимое хранилище, а затем умеет безопасно вернуть отсутствующие файлы. Существующие данные Claude при восстановлении не перезаписываются.

Приложение не использует официальный экспорт, не требует аккаунта и ничего не отправляет в интернет. Поддерживаются Windows, macOS и Linux; пути можно изменить в настройках.

Разработка: `npm install`, затем `npm run tauri dev`. Проверка: `npm run check` и `cargo test --manifest-path src-tauri/Cargo.toml`. Подробный формат архива описан в [docs/archive-format.md](docs/archive-format.md).

Независимый проект, не связанный с Anthropic. Лицензия MIT.
