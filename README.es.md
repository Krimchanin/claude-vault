# Claude Vault

[English](README.md) · [Русский](README.ru.md) · [简体中文](README.zh-CN.md) · [Deutsch](README.de.md) · **Español** · [Français](README.fr.md)

**Cambia de cuenta de Claude sin perder el historial.** Claude Vault es una herramienta de escritorio no oficial y local para ver, respaldar y restaurar datos de Claude Desktop y Claude Code directamente desde el sistema de archivos.

Claude Desktop puede eliminar los chats locales visibles al cambiar de cuenta. Claude Vault conserva metadatos, transcripciones JSONL completas, adjuntos y archivos de trabajo en un almacén independiente. La restauración solo añade archivos ausentes y nunca sobrescribe datos existentes de Claude.

No usa la exportación oficial, no requiere cuenta y no sube datos. Compatible con Windows, macOS y Linux, con rutas configurables. Desarrollo: `npm install` y `npm run tauri dev`. Consulta [docs/archive-format.md](docs/archive-format.md) para conocer el formato.
